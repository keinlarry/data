Analyse de la Fidélisation Client (Churn) — ML en Production

Projet end-to-end déployé en production : de l'analyse exploratoire jusqu'au pipeline CI/CD automatisé. À partir d'un dataset déséquilibré (~20% de churn), j'ai comparé cinq algorithmes de classification et retenu un Gradient Boosting optimisé par RandomizedSearchCV (ROC-AUC : 0.87). Le modèle est exposé via une API REST FastAPI et un dashboard Streamlit interactif avec explicabilité individuelle par SHAP (waterfall plot par client). Un pipeline GitHub Actions bloque automatiquement tout déploiement si les tests régressent.

Python · Scikit-Learn · FastAPI · Streamlit · SHAP · Pytest · GitHub Actions · Render
